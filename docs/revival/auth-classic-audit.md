# Classic 1.7 under authority: audit and fixes

2026-10-22. The user's direction: Neue is backseated; classic 1.7 RevivalPaper PvP under authority comes first, "solid
as hell". The NAS world runs rule set `classic-capped` (classic plus the 12 CPS cap and the 0.15 s click buffer).

An audit read the merged tree through four lenses: the 66-row 1.7 issue checklist (`pvp-issues.md`), one classic
exchange end to end, the cheats that matter in classic HCF, and the fights no rig plays. A skeptic checked each gap
against the code before it counted. 14 work items survived, plus 4 rows that `pvp-issues.md` already tracks. Seven
claims were refuted.

## Where a claim can win: the review (2026-10-22, night)

The keep-sprint row (#17) showed that "impossible by design" can hide a path where the server takes the client's word.
Every such path, checked:

| Path | What reaches the truth or vanilla | Verdict |
|---|---|---|
| `retryAttackStrength` (the correction's "the hit was weak" branch) | a claim matching the flipped strength's movement | was the KeepSprint hole (#17); now only a strength the ticker could have had |
| `retryWithSlot` (a hotbar key in the same window) | the claim of the tick re-run with the new slot's item | safe: it only explains what the slot change really does on the server |
| Exempt "not loaded" | the move, replayed to vanilla | was a full bypass once Paper's load timeout passed (#18); never replayed now |
| Exempt "chunk-unknown" | the move, replayed to vanilla | hardened (#19): only for a chunk the server sent |
| Exempt warm-up (until the first pong after activation) | the claim seeds the truth, the move goes to vanilla | bounded: a client that holds its pongs is frozen within `max-unacked-ms` (1.5 s), and it happens only at activation |
| Exempt "external mover" (an inexact boat, shulker or happy ghast copy in contact, a geyser) | the move to vanilla, at most `external-movers.max-move` (1.0) per axis per tick | bounded: contact ends within a block; a copy made inexact by held pongs is re-paired, the holder frozen within 1.5 s (cheat suite 2 boat and shulker rows) |
| Exempt riptide spin | the move to vanilla for the spin | open, low: needs a riptide trident and water or rain; the port doesn't model the spin yet |
| Piston and shulker-box pushes | the part of the claim along the push | bounded by #4 |
| The attack eye offset | the eye a hit is judged from | gated by #1 |
| Claims off by less than the correction threshold, sub-µm claims | nothing: neither corrected at once nor adopted (`rebase-epsilon` 0) | safe |
| Refused windows (timer) | nothing: no physics, claims ignored, never replayed | safe |
| Teleport accepts | judged as claims (MV-6) | safe |
